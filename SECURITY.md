# Security Policy

PLATE-X is intended for lawful investigation, security research, education, and authorized data access.

## Sensitive data

Never commit real owner personal information, government IDs, credentials, API keys, private evidence, or leaked databases.

Use synthetic data for tests and demonstrations.

## Vulnerability reports

Do not publish exploitable vulnerabilities or sensitive information in public issues. Use GitHub's private security reporting mechanism when available.

## Responsible use

PLATE-X must not be used to obtain, aggregate, publish, or redistribute private vehicle-owner information without lawful authorization.
